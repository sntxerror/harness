# V0.5 — Delegation & foreign CLI workers (plan stages 9, 10, 11 local)

Value: work is delegated — to parallel worktree children and to Claude Code, Codex and Antigravity running under compiled provider profiles on our capability surface, not their vendor defaults. This is the largest single step toward parity (ADR-040/042).

Everything in this version is local. The canonical MCP registry and lazy proxy are built here because foreign workers need a generated `.mcp.json` before any server exists; relocating them to the server is V0.7 and changes no contract.
