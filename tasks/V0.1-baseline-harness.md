# V0.1 — Baseline interactive harness (plan stages 0–2)

Value: a daily-usable local Pi session with intent gating, real PTY and structured questions — safe enough to work in immediately.

**Scope is the workstation.** Server provisioning moved to V0.7 (ADR-040), so nothing here depends on the remote host. The one server item that does not wait is the sudoers time-box: a standing privilege on a host whose work is paused is exactly the failure ADR-038 was written against, so it is revoked now rather than held until V0.7.

Recorded here because T1 must not rediscover it and T2's decision depends on it.

| `claude` 2.1.210, `codex-cli` 0.145.0, `agy` 1.1.4 | All three installed | V0.5 needs no provisioning; the V0.6 parity comparison is directly runnable |

The `rg` finding is worth more than its size. `command -v rg` succeeds in the login shell and fails in a non-interactive executor, because a shell function is not on `PATH`. That is R-003 — a profile advertising a command the executor cannot resolve — reproduced on this machine before any of our code exists. It is the reference case for V0.3-T2's preflight, and T1's inventory must therefore be taken inside the executor rather than from an interactive prompt.
